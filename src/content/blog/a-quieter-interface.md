## Leave some space

Not every part of a page needs to say something. Space gives the important things room to be noticed.

For this little corner of the web, the constraints are deliberately simple:

1. Four destinations, each with a clear purpose.
2. One accent color.
3. Typography that feels at home in a terminal.
4. No decoration pretending to be a working control.

## Make the basics comfortable

An interface can be minimal without being difficult. Text should be readable, focus should be visible, and links should work without surprises.

| Keep | Leave behind |
| --- | --- |
| Clear navigation | Hidden gestures |
| Real content | Decorative metrics |
| A readable measure | Edge-to-edge paragraphs |

### A small checklist

Before adding another element, ask: **does this help someone understand, read, or act?**

If not, perhaps the page is already finished.
